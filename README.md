# Fitness – SWAFE hand-in 2

A Next.js web app where a manager creates personal trainers, trainers create clients and workout programs, and clients see their programs. It uses the backend at <https://assignment2.swafe.dk>.

Prefix: `g10`

## Run locally

```bash
npm install
npm run dev
```

Create `.env.local` with `API_URL=https://assignment2.swafe.dk` first. Then open <http://localhost:3000>.
